# 🎬 Sistemas de Recomendação

Projeto acadêmico desenvolvido para a implementação de **Sistemas de Recomendação** utilizando Python e os datasets `movies.csv` e `ratings.csv`.

O projeto apresenta duas abordagens de recomendação:

### 1. ⭐ Best Seller

Sistema que recomenda filmes com base na sua popularidade e desempenho nas avaliações dos usuários, identificando os filmes mais bem avaliados e/ou mais relevantes dentro do conjunto de dados.

### 2. 🎯 Similaridade

Sistema que utiliza a **similaridade entre filmes** para encontrar títulos semelhantes e gerar recomendações com base nas características e avaliações disponíveis nos dados.

## 📂 Arquivos

* `movies.csv` — informações sobre os filmes.
* `ratings.csv` — avaliações realizadas pelos usuários.
* `Sistemas_de_recomendacao_Moveis.ipynb` — implementação dos sistemas utilizando os dados de filmes.
* `Sistemas_recomendacao_Ratings.ipynb` — implementação dos sistemas utilizando os dados de avaliações.

## 🛠️ Tecnologias utilizadas

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Sistemas de Recomendação
* Análise de Dados

## 🎯 Objetivo

O objetivo do projeto é aplicar conceitos de **Sistemas de Recomendação** para desenvolver diferentes estratégias capazes de sugerir filmes aos usuários, comparando uma abordagem baseada em popularidade (**Best Seller**) com uma abordagem baseada em **similaridade**.
